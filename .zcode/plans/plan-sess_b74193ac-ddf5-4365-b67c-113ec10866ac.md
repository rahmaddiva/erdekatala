# Menyelesaikan Fitur Peta GeoJSON (MapLibre GL)

## Temuan
Fitur sudah ~95% jadi: aset GeoJSON BPS sudah diproses ke `public/geojson/` (`kecamatan.geojson`, `desa/001–011.geojson`, `kabupaten.geojson`), plugin MapLibre GL v5.8.0 sudah di-vendor di `public/assets/plugins/maplibre/`, kedua view publik (`landingpage.php`, `kecamatan.php`) sudah punya kode peta lengkap (merge data, popup, legend, hover), dan controller sudah menyuplai data join-key yang konsisten (`kodeKecamatan3` ↔ `kd_kecamatan`, `getDesaStats` ↔ `kd_kecamatan.kd_kelurahan`).

Yang tersisa adalah 3 perbaikan bug + 1 polesan + verifikasi menyeluruh.

## Perbaikan Bug

### 1. Race condition: `setData` dijalankan sebelum map selesai load (penyebab peta gagal tampil)
Di kedua view, `map.getSource('kecamatan'/'desa').setData(...)` dipanggil di dalam `fetch().then()` — di localhost, fetch file GeoJSON (lokal, cepat) bisa selesai SEBELUM event `load` MapLibre → `getSource()` mengembalikan undefined → TypeError → masuk `.catch()` → seluruh peta diganti placeholder error.
- `landingpage.php` (~baris 2211): pindahkan `setData` kecamatan + `fitBounds` ke dalam `whenLoaded(...)`.
- `kecamatan.php` (~baris 1679): pindahkan `setData` desa ke dalam `whenLoaded(...)`.

### 2. Urutan layer salah: hover putih di atas poligon desa
Di `landingpage.php`, layer `kec-hover` (highlight putih saat hover) dideklarasikan SETELAH `desa-fill`/`desa-line`, sehingga saat kecamatan difilter, overlay desa tertimpa tint putih. Pindahkan `kec-hover` sebelum layer desa.

### 3. URL popup rapuh (concat string PHP di dalam JS)
`'<?= site_url('/') ?>' + k.slug` rawan patah jika baseURL tak berakhiran `/`. Ganti dengan `<?= json_encode(site_url('/')) ?> + k.slug` (hal yang sama di `kecamatan.php` baris 1672).

## Polesan (memakai aset yang sudah disiapkan tapi belum terpakai)

### 4. Garis batas kabupaten di peta landing
`kabupaten.geojson` (204 KB) sudah dibuat command `geojson:prepare` tapi tidak direferensikan. Tambahkan source + layer `kab-line` (outline tipis) di style inline landing page sebagai konteks batas kabupaten, fetch + setData di dalam `whenLoaded`.

## Regenerasi & Migrasi

### 5. Perintah
- `php spark geojson:prepare` — regenerasi `public/geojson/` deterministik dari sumber root (idempotent).
- `php spark migrate` — terapkan migration `RenameMekarSariToMekarRaya` bila belum (Seeder sudah sinkron: `WilayahSeeder.php:177` sudah memakai "Mekar Raya").

## Verifikasi

### 6. Lint & uji browser
- `php -l` semua file PHP yang diubah.
- Uji browser (browser-use, localhost):
  - `/` landing: peta tampil, poligon kecamatan berwarna sesuai total jiwa, legend terisi, klik poligon → popup, klik link detail, filter `?kecamatan=<slug>` → overlay poligon desa muncul.
  - `/<slug kecamatan>` (mis. `/kurau`): peta desa tampil, popup + link detail desa.
  - Cek console browser bebas error.

## Catatan (tidak dikerjakan, hanya info)
- File sumber BPS di root (`63.01_*.geojson`, total ±11 MB) adalah input `geojson:prepare`; bila ingin repo ringan, bisa ditambahkan ke `.gitignore` — tapi keputusan ini saya serahkan ke Anda.
- Jika tabel `laporan_agregat` kosong, poligon tampil abu-abu (by design); verifikasi visual warna butuh data laporan yang sudah terisi.
