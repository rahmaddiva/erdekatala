# Refactor Peta Publik: MapLibre GL → Leaflet 1.9.4 (file lokal)

## Konteks
Halaman publik `landingpage.php` dan `kecamatan.php` saat ini memakai **MapLibre GL JS 5.8.0** (WebGL) untuk peta choropleth sebaran kependudukan. User ingin refactor ke **Leaflet.js** (sesuai https://leafletjs.com/reference.html) menggunakan file yang sudah didownload di `public/leaflet/` (terverifikasi: Leaflet **1.9.4** lengkap — `leaflet.js`, `leaflet.css`, `images/` termasuk marker icon). Bonus: Leaflet berbasis SVG/DOM, jadi masalah fallback WebGL yang ada sekarang hilang.

**Yang TIDAK berubah (kontrak data kompatibel):** `PublicController.php` (`map_kecamatan`, `desa_stats`, `kecamatanCoordinatesMap`), semua file GeoJSON di `public/geojson/`, migrations, seeder.

## Perubahan

### 1. Ganti asset include (2 view)
- `landingpage.php` baris 65 & ~1788, `kecamatan.php` baris 68 & ~1461:
  - CSS → `<?= base_url('leaflet/leaflet.css') ?>`
  - JS → `<?= base_url('leaflet/leaflet.js') ?>`

### 2. Tulis ulang IIFE peta di `landingpage.php` (baris 1968–2352) ke API Leaflet
Pemetaan MapLibre → Leaflet:
- Guard `typeof maplibregl` → `typeof L`; **hapus cek WebGL** (tidak perlu); pertahankan placeholder "belum ada data" & ubah pesan error library.
- `new maplibregl.Map(...)` → `L.map('map-kecamatan', { scrollWheelZoom: false, zoomControl: false })` + `L.control.zoom({ position: 'topright' })` (meniru NavigationControl top-right) + view awal sementara `setView([-3.8, 114.75], 8)`.
- Basemap tetap **CARTO Voyager** (tampilan sama): `L.tileLayer('https://basemaps.cartocdn.com/rastertiles/voyager/{z}/{x}/{y}.png', { attribution: OSM+CARTO, maxZoom: 19 })`.
- Choropleth: `L.geoJSON(fc, { style, onEachFeature })`. Fungsi `style(feature)` menggantikan expression `case/match`: isActive → `#2d6cdf`, hasData → `RAMP[bucket]`, tanpa data → `#e5e1d8`; `fillOpacity: 0.85`, garis putih 1.2px. `RAMP`, `makeBucketFn`, `mergeKec`, `mergeDesa` dipertahankan apa adanya.
- Hover (feature-state → event layer): `mouseover` → `setStyle` fillColor di-blend 40% putih (ekuivalen overlay `kec-hover`) + `bringToFront()` + cursor pointer; `mouseout` → `resetStyle()`.
- Popup: `maplibregl.Popup` bersama → `layer.bindPopup(html, { className: 'map-popup-kec', closeButton: false })`; isi HTML `kecPopupHtml`/`desaPopupHtml` tidak berubah.
- Lazy-load desa (`loadDesa`): fetch → `L.geoJSON` desa ditambahkan setelah layer kecamatan (gambar di atasnya).
- Garis batas kabupaten putus-putus: `L.geoJSON(kab, { style: { color:'#5b6472', weight:1.6, opacity:.9, dashArray:'8,4', fill:false }, interactive:false })` ditambahkan terakhir (urutan layer sama dengan MapLibre).
- Helper manual `featureBounds`/`collectionBounds` **dihapus** → pakai `layer.getBounds()` bawaan Leaflet.
- fitBounds: kecamatan aktif → `fitBounds(bounds, { padding:[60,60] })`; fallback → `flyTo([activeKec.lat, activeKec.lng], 9)` (hati-hati urutan Leaflet **[lat, lng]**); tanpa filter → fitBounds seluruh features padding 40.
- Error tile: `tileLayer.on('tileerror')` dengan counter; catatan di legenda `#map-legend-kec` setelah 3 kegagalan (perilaku sama).
- Kode legenda `lg-0..lg-4` tidak berubah.
